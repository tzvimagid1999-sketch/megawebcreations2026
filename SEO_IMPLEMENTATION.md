## Image Optimization

### Alt Text Convention:
`[Service] - [What it does/benefit]`

Examples:
- `Custom website design - Conversion-optimized homepage for service business`
- `AI chatbot - Customer service automation that responds 24/7`
- `Email automation - Marketing email sequences for lead nurturing`

### Image Format:
- Use WebP with JPEG fallback for web
- Lazy load images (Next.js image component)
- Responsive images (srcset)
- Descriptive filenames: custom-website-hero.webp
